MW4 Camo Sheet - camo tracker application

1. Right-click the zip > Extract All (don't run it from inside the zip).
2. Double-click "MW4 Camo Sheet.exe".
3. If Windows shows "Windows protected your PC", click "More info" > "Run anyway".
   (It only says that because the app isn't from a registered publisher.)

Your progress saves automatically to progress.json in the same folder.
Keep the .exe in a normal folder (Desktop, Documents) so it can save.
